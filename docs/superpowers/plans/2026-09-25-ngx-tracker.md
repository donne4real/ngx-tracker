# NGX Tracker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A private, $0 website showing every NGX stock's latest end-of-day close, day/week/month changes, top gainers/losers, and per-stock price history, refreshed automatically each trading day.

**Architecture:** A Node/TypeScript pipeline, run by GitHub Actions on weekdays, pulls one all-stocks snapshot from Kobo Terminal (only once the market is closed), backfills about a year of history per stock from EODHD (up to 18 stocks per run), and writes plain JSON files to `data/`, committed to the repo. A static React site reads those files. It is deployed to Cloudflare Pages behind Cloudflare Access (email one-time-code sign-in).

**Tech Stack:** Node 22+, TypeScript, Vitest, tsx; React 18+, Vite, TradingView `lightweight-charts` v5, Testing Library; GitHub Actions; Cloudflare Pages + Access (`wrangler`).

**Spec:** `docs/superpowers/specs/2026-09-25-ngx-tracker-design.md` — read it alongside this plan. It holds the definitions (§3.3) and the recorded real API formats (§7).

## Global Constraints

- Cost: $0. Kobo free Personal plan (100 req/day; **1 per run**) and EODHD free plan (20 req/day; **≤18 per run**, backfill only).
- Kobo: `GET https://koboterminal.com/api/ngxdata/stocks`, header `X-API-Key`. Price = `current_price`; date = `market.trade_date` (first 10 chars).
- **Never store a bar while `market.market_status === "open"`** — exit cleanly without writing.
- Validation: at least **100** valid stocks (symbol matching `^[A-Z0-9][A-Z0-9.]*$`, numeric `current_price` > 0); otherwise throw and write nothing.
- EODHD: `https://eodhd.com/api/eod/<SYMBOL>.XNSA`; use unadjusted `close`; only dates **before** the stock's first Kobo date. EODHD errors never fail the run. HTTP 429/402 stops further backfills for the run.
- Inactive after **10** consecutive missing trading days (never deleted).
- Changes: day = vs previous stored bar; week = vs last close on/before latest − 7 calendar days; month = on/before latest − 1 calendar month (day clamped to month end); `null` if history is too short; rounded to 2 dp.
- Movers: top **10** gainers (change > 0) and losers (change < 0) per horizon; exclude inactive, not traded on the latest day (`volume === 0` or last bar ≠ as-of date), and `null`.
- Large-move flag: |day change| > **10**%.
- Stale banner: latest trade date more than **4** weekdays before the viewing date. The spec says "build date"; the site only rebuilds when data changes, so the viewing date is the one that can actually detect staleness.
- Secrets live only in `.env` (git-ignored) locally and in GitHub Actions secrets. Never in code, `data/`, logs, error messages or the built site.
- Website only; hash routes `#/` and `#/stock/:symbol`; works on phones; follows system light/dark.
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Kobo called during trading hours, or returning no `market` block** → nothing is saved (market open) or the run fails loudly (no market block). A mid-day price must never be stored as the close. *Pinned in Task 2 (missing market → ValidationError) and Task 6 (open → no files written).*
2. **A stock that didn't trade today, or has gone inactive** → still listed in the table (inactive hidden until "Show inactive" is ticked) but never in the gainers/losers lists. *Pinned in Task 4 (movers exclusions) and Task 8 (table hides inactive).*
3. **A bonus issue or split (e.g. a −50% day)** → still shown, but flagged ⚠ as a possible corporate action. *Pinned in Task 4.*
4. **Calendar edges** — a holiday inside the week look-back, and month-back from Mar 31 → the correct earlier close, not an error or a wrong day. *Pinned in Task 1 (date math) and Task 4 (changes).*
5. **Opening a stock URL that isn't tracked, or getting Cloudflare's HTML page instead of JSON** → a clear "Stock not found" message, not a blank page or crash. *Pinned in Task 7 (loader returns null on HTML/404) and Task 9 (page shows not-found).*

```ts
const ISO_RE = /^(\d{4})-(\d{2})-(\d{2})/;

/** Date part of an ISO date/timestamp: "2026-09-25T00:00:00" -> "2026-09-25". */
export function toISODate(value: string): string {
  const m = ISO_RE.exec(value);
  if (!m) throw new Error(`Not an ISO date: ${JSON.stringify(value)}`);
  return `${m[1]}-${m[2]}-${m[3]}`;
}

function toUTC(date: string): Date {
  const [y, m, d] = toISODate(date).split('-').map(Number);
  return new Date(Date.UTC(y, m - 1, d));
}

function fromUTC(dt: Date): string {
  return dt.toISOString().slice(0, 10);
}

export function addDays(date: string, days: number): string {
  const dt = toUTC(date);
  dt.setUTCDate(dt.getUTCDate() + days);
  return fromUTC(dt);
}

/** Same day-of-month `months` earlier, clamped to that month's last day. */
export function minusMonths(date: string, months: number): string {
  const [y, m, d] = toISODate(date).split('-').map(Number);
  const target = new Date(Date.UTC(y, m - 1 - months, 1));
  const lastDay = new Date(Date.UTC(target.getUTCFullYear(), target.getUTCMonth() + 1, 0)).getUTCDate();
  target.setUTCDate(Math.min(d, lastDay));
  return fromUTC(target);
}

/** Number of Mon–Fri days after `from`, up to and including `to` (0 if to <= from). */
export function weekdaysAfter(from: string, to: string): number {
  let count = 0;
  for (let d = addDays(from, 1); d <= to; d = addDays(d, 1)) {
    const day = toUTC(d).getUTCDay();
    if (day !== 0 && day !== 6) count++;
  }
  return count;
}
```

```ts
import { toISODate } from './dates.js';
import type { KoboStock, Snapshot } from './types.js';

export const KOBO_URL = 'https://koboterminal.com/api/ngxdata/stocks';
const SYMBOL_RE = /^[A-Z0-9][A-Z0-9.]*$/;

export class ValidationError extends Error {
  override name = 'ValidationError';
}

type Obj = Record<string, unknown>;
const isObj = (v: unknown): v is Obj => typeof v === 'object' && v !== null && !Array.isArray(v);
const num = (v: unknown, fallback: number) => (typeof v === 'number' && Number.isFinite(v) ? v : fallback);
const str = (v: unknown, fallback: string) => (typeof v === 'string' && v.trim() !== '' ? v.trim() : fallback);

function isoOrNull(v: unknown): string | null {
  if (typeof v !== 'string') return null;
  try {
    return toISODate(v);
  } catch {
    return null;
  }
}

export function parseKoboSnapshot(json: unknown, { minStocks = 100 }: { minStocks?: number } = {}): Snapshot {
  if (!isObj(json) || !Array.isArray(json.stocks)) {
    throw new ValidationError('Kobo response has no stocks array');
  }
  const m = json.market;
  const tradeDate = isObj(m) ? isoOrNull(m.trade_date) : null;
  if (!isObj(m) || typeof m.market_status !== 'string' || tradeDate === null) {
    throw new ValidationError('Kobo response has no market status or trade date');
  }

  const warnings: string[] = [];
  const stocks: KoboStock[] = [];
  for (const s of json.stocks) {
    if (!isObj(s) || typeof s.symbol !== 'string' || !SYMBOL_RE.test(s.symbol)) {
      warnings.push(`Skipped a stock with an invalid symbol: ${JSON.stringify(isObj(s) ? s.symbol : s)}`);
      continue;
    }
    if (typeof s.current_price !== 'number' || !Number.isFinite(s.current_price) || s.current_price <= 0) {
      warnings.push(`Skipped ${s.symbol}: no valid current_price`);
      continue;
    }
    const own = isoOrNull(s.trade_date);
    if (own !== null && own !== tradeDate) {
      warnings.push(`Skipped ${s.symbol}: trade date ${own} differs from market date ${tradeDate}`);
      continue;
    }
    stocks.push({
      symbol: s.symbol,
      name: str(s.name, s.symbol),
      close: s.current_price,
      volume: Math.max(0, num(s.volume, 0)),
      sector: str(s.sector, 'Unclassified'),
      board: str(s.market, ''),
      marketCap: num(s.market_cap, 0),
    });
  }
  if (stocks.length < minStocks) {
    throw new ValidationError(`Only ${stocks.length} valid stocks in the Kobo response (need at least ${minStocks})`);
  }
  return {
    tradeDate,
    stocks,
    market: {
      asi: num(m.asi, 0),
      pctChange: num(m.pct_change, 0),
      advancers: num(m.advancers, 0),
      decliners: num(m.decliners, 0),
      unchanged: num(m.unchanged, 0),
      status: m.market_status,
    },
    warnings,
  };
}

export async function fetchKobo(apiKey: string, fetchImpl: typeof fetch = fetch): Promise<unknown> {
```

```ts
import type { Bar, History, Snapshot, StockMeta, StocksFile } from './types.js';

export const INACTIVE_AFTER = 10;

const byDate = (a: Bar, b: Bar) => (a.date < b.date ? -1 : a.date > b.date ? 1 : 0);

export function isNewTradeDate(file: StocksFile, tradeDate: string): boolean {
  return file.lastTradeDate === null || tradeDate > file.lastTradeDate;
}

/** Adds one bar per snapshot stock (mutating `histories`) and returns the updated stock list. */
export function appendSnapshot(file: StocksFile, histories: Map<string, History>, snap: Snapshot): StocksFile {
  const bySymbol = new Map<string, StockMeta>(file.stocks.map((s) => [s.symbol, { ...s }]));
  const seen = new Set<string>();

  for (const k of snap.stocks) {
    seen.add(k.symbol);
    const prev = bySymbol.get(k.symbol);
    bySymbol.set(k.symbol, {
      symbol: k.symbol,
      name: k.name,
      sector: k.sector,
      board: k.board,
      marketCap: k.marketCap,
      status: 'active',
      missingDays: 0,
      firstKoboDate: prev?.firstKoboDate ?? snap.tradeDate,
      backfill: prev?.backfill ?? 'pending',
      backfillAttempts: prev?.backfillAttempts ?? 0,
    });

    const h = histories.get(k.symbol) ?? { symbol: k.symbol, bars: [] };
    if (!h.bars.some((b) => b.date === snap.tradeDate)) {
      h.bars.push({ date: snap.tradeDate, close: k.close, volume: k.volume, traded: k.volume > 0, source: 'kobo' });
      h.bars.sort(byDate);
    }
    histories.set(k.symbol, h);
  }

  for (const [symbol, m] of bySymbol) {
    if (seen.has(symbol)) continue;
    m.missingDays += 1;
    if (m.missingDays >= INACTIVE_AFTER) m.status = 'inactive';
  }

  return {
    lastTradeDate: snap.tradeDate,
    stocks: [...bySymbol.values()].sort((a, b) => a.symbol.localeCompare(b.symbol)),
  };
}
```

```ts
import { addDays, minusMonths } from './dates.js';
import type { Bar, Changes, History, Horizon, MarketInfo, MoverRow, Movers, StocksFile, Summary, SummaryRow } from './types.js';

export const LARGE_MOVE_PCT = 10;
export const MOVERS_COUNT = 10;
const HORIZONS: Horizon[] = ['day', 'week', 'month'];

const pct = (now: number, then: number) => Math.round((now / then - 1) * 10000) / 100;

/** Last bar dated on or before `date` (bars sorted ascending). */
export function closeOnOrBefore(bars: Bar[], date: string): Bar | undefined {
  for (let i = bars.length - 1; i >= 0; i--) if (bars[i].date <= date) return bars[i];
  return undefined;
}

export function computeChanges(bars: Bar[]): Changes {
  const last = bars.at(-1);
  if (!last) return { day: null, week: null, month: null };
  const prev = bars.length > 1 ? bars[bars.length - 2] : undefined;
  const week = closeOnOrBefore(bars, addDays(last.date, -7));
  const month = closeOnOrBefore(bars, minusMonths(last.date, 1));
  return {
    day: prev ? pct(last.close, prev.close) : null,
    week: week ? pct(last.close, week.close) : null,
    month: month ? pct(last.close, month.close) : null,
  };
}

function movers(rows: SummaryRow[], h: Horizon): Movers {
  const eligible = rows
    .filter((r) => r.status === 'active' && r.traded && r.changes[h] !== null)
    .map<MoverRow>((r) => ({ symbol: r.symbol, name: r.name, close: r.close, change: r.changes[h] as number, largeMove: r.largeMove }));
  const bySymbol = (a: MoverRow, b: MoverRow) => a.symbol.localeCompare(b.symbol);
  return {
    gainers: eligible.filter((r) => r.change > 0).sort((a, b) => b.change - a.change || bySymbol(a, b)).slice(0, MOVERS_COUNT),
    losers: eligible.filter((r) => r.change < 0).sort((a, b) => a.change - b.change || bySymbol(a, b)).slice(0, MOVERS_COUNT),
  };
}

export function buildSummary(
  file: StocksFile,
  histories: Map<string, History>,
  market: MarketInfo,
  asOf: string,
  generatedAt: string,
): Summary {
  const rows: SummaryRow[] = [];
  for (const m of file.stocks) {
    const bars = histories.get(m.symbol)?.bars ?? [];
    const last = bars.at(-1);
    if (!last) continue;
    const changes = computeChanges(bars);
    rows.push({
      symbol: m.symbol,
      name: m.name,
      sector: m.sector,
      board: m.board,
      status: m.status,
      close: last.close,
      volume: last.volume,
      traded: last.date === asOf && last.traded,
      lastDate: last.date,
      historyStart: bars[0].date,
      changes,
      largeMove: changes.day !== null && Math.abs(changes.day) > LARGE_MOVE_PCT,
    });
  }
  const noTrade = rows.filter((r) => r.status === 'active' && !r.traded).length;
  return {
    asOf,
    generatedAt,
    market: { ...market, noTrade },
    stocks: rows,
    movers: Object.fromEntries(HORIZONS.map((h) => [h, movers(rows, h)])) as Record<Horizon, Movers>,
  };
}
```

```ts
  const out: Bar[] = [];
  for (const r of json as Row[]) {
    if (!r || typeof r.date !== 'string' || typeof r.close !== 'number' || !(r.close > 0)) continue;
    let date: string;
    try {
      date = toISODate(r.date);
    } catch {
      continue;
    }
    const volume = typeof r.volume === 'number' && r.volume > 0 ? r.volume : 0;
    out.push({ date, close: r.close, volume, traded: volume > 0, source: 'eodhd' });
  }
  return out;
}

/** Error messages never include the URL, because the URL carries the API key. */
export async function fetchEodhd(
  symbol: string,
  from: string,
  to: string,
  apiKey: string,
  fetchImpl: typeof fetch = fetch,
): Promise<unknown> {
  const url =
    `https://eodhd.com/api/eod/${encodeURIComponent(symbol)}.XNSA` +
    `?period=d&fmt=json&from=${from}&to=${to}&api_token=${encodeURIComponent(apiKey)}`;
  const res = await fetchImpl(url);
  if (res.status === 429 || res.status === 402) {
    throw new EodhdLimitError(`EODHD daily limit reached (HTTP ${res.status})`);
  }
  if (!res.ok) throw new Error(`EODHD HTTP ${res.status}`);
  return res.json();
}
```

```ts
import { addDays, minusMonths } from './dates.js';
import type { Bar, History, StockMeta, StocksFile } from './types.js';

export const BACKFILL_PER_RUN = 18;
export const MAX_BACKFILL_ATTEMPTS = 3;

export function pickBackfills(file: StocksFile, limit = BACKFILL_PER_RUN): StockMeta[] {
  return file.stocks
    .filter((s) => s.status === 'active' && s.backfill === 'pending' && s.firstKoboDate !== null)
    .sort((a, b) => b.marketCap - a.marketCap || a.symbol.localeCompare(b.symbol))
    .slice(0, limit);
}

export function backfillRange(firstKoboDate: string): { from: string; to: string } {
  return { from: addDays(minusMonths(firstKoboDate, 12), -7), to: addDays(firstKoboDate, -1) };
}

/** EODHD fills only the dates before the first Kobo day, so the two sources never overlap. */
export function mergeBackfill(h: History, eodBars: Bar[], firstKoboDate: string): History {
  const earliest = h.bars[0]?.date ?? firstKoboDate;
  const cutoff = earliest < firstKoboDate ? earliest : firstKoboDate;
  const have = new Set(h.bars.map((b) => b.date));
  const added = eodBars.filter((b) => b.date < cutoff && !have.has(b.date));
  const bars = [...added, ...h.bars].sort((a, b) => (a.date < b.date ? -1 : a.date > b.date ? 1 : 0));
  return { symbol: h.symbol, bars };
}
```

```ts
import { mkdir, readFile, writeFile } from 'node:fs/promises';
import { dirname, join } from 'node:path';
import type { History, Report, StocksFile, Summary } from './types.js';

/** One bar per line, so daily git diffs show exactly the new rows. */
export function formatHistory(h: History): string {
  const lines = h.bars.map((b) => '    ' + JSON.stringify(b));
  return `{\n  "symbol": ${JSON.stringify(h.symbol)},\n  "bars": [\n${lines.join(',\n')}\n  ]\n}\n`;
}

export class DataStore {
  constructor(readonly dir: string) {}

  async readStocks(): Promise<StocksFile> {
    return (await this.readJson<StocksFile>('stocks.json')) ?? { lastTradeDate: null, stocks: [] };
  }

  async readHistories(symbols: Iterable<string>): Promise<Map<string, History>> {
    const map = new Map<string, History>();
    for (const s of symbols) {
      const h = await this.readJson<History>(`history/${s}.json`);
      if (h) map.set(s, h);
    }
    return map;
  }

  writeStocks(f: StocksFile) {
    return this.writeText('stocks.json', JSON.stringify(f, null, 2) + '\n');
  }
  writeHistory(h: History) {
    return this.writeText(`history/${h.symbol}.json`, formatHistory(h));
  }
  /** Compact: the website downloads this file on every visit. */
  writeSummary(s: Summary) {
    return this.writeText('summary.json', JSON.stringify(s) + '\n');
  }
  writeReport(r: Report) {
    return this.writeText('report.json', JSON.stringify(r, null, 2) + '\n');
  }

  private async readJson<T>(rel: string): Promise<T | null> {
    try {
      return JSON.parse(await readFile(join(this.dir, rel), 'utf8')) as T;
    } catch (e) {
      if ((e as NodeJS.ErrnoException).code === 'ENOENT') return null;
      throw e;
    }
  }

  private async writeText(rel: string, text: string): Promise<void> {
    const p = join(this.dir, rel);
    await mkdir(dirname(p), { recursive: true });
    await writeFile(p, text, 'utf8');
  }
}
```

```ts
import { BACKFILL_PER_RUN, MAX_BACKFILL_ATTEMPTS, backfillRange, mergeBackfill, pickBackfills } from './backfill.js';
import { EodhdLimitError, parseEodhd } from './eodhd.js';
import { parseKoboSnapshot } from './kobo.js';
import { appendSnapshot, isNewTradeDate } from './merge.js';
import { buildSummary } from './metrics.js';
import type { DataStore } from './store.js';
import type { Report } from './types.js';

export interface RunDeps {
  fetchKobo: () => Promise<unknown>;
  fetchEodhd: (symbol: string, from: string, to: string) => Promise<unknown>;
  store: DataStore;
  now: () => Date;
  minStocks?: number;
  backfillPerRun?: number;
}

export async function runDaily(deps: RunDeps): Promise<Report> {
  const snap = parseKoboSnapshot(await deps.fetchKobo(), { minStocks: deps.minStocks });
  const report: Report = {
    runAt: deps.now().toISOString(),
    outcome: 'appended',
    tradeDate: snap.tradeDate,
    backfill: { ok: [], failed: [], stoppedEarly: null },
    warnings: [...snap.warnings],
  };

  // Kobo's prices keep moving until the close; never store an intraday price.
  if (snap.market.status === 'open') return { ...report, outcome: 'market-open' };

  let file = await deps.store.readStocks();
  // Weekend, holiday or a second scheduled attempt: nothing new, and no EODHD calls.
  if (!isNewTradeDate(file, snap.tradeDate)) return { ...report, outcome: 'duplicate-date' };

  const symbols = new Set([...file.stocks.map((s) => s.symbol), ...snap.stocks.map((s) => s.symbol)]);
  const histories = await deps.store.readHistories(symbols);
  file = appendSnapshot(file, histories, snap);

  for (const meta of pickBackfills(file, deps.backfillPerRun ?? BACKFILL_PER_RUN)) {
    const first = meta.firstKoboDate as string;
    const { from, to } = backfillRange(first);
    try {
      const bars = parseEodhd(await deps.fetchEodhd(meta.symbol, from, to));
      if (bars.length === 0) throw new Error('EODHD returned no prices');
      const current = histories.get(meta.symbol) ?? { symbol: meta.symbol, bars: [] };
      histories.set(meta.symbol, mergeBackfill(current, bars, first));
      meta.backfill = 'done';
      report.backfill.ok.push(meta.symbol);
    } catch (err) {
      if (err instanceof EodhdLimitError) {
        report.backfill.stoppedEarly = err.message;
        break;
      }
      meta.backfillAttempts += 1;
      if (meta.backfillAttempts >= MAX_BACKFILL_ATTEMPTS) meta.backfill = 'failed';
      report.backfill.failed.push({ symbol: meta.symbol, error: err instanceof Error ? err.message : String(err) });
    }
  }

  const summary = buildSummary(file, histories, snap.market, snap.tradeDate, report.runAt);
  for (const h of histories.values()) await deps.store.writeHistory(h);
  await deps.store.writeStocks(file);
  await deps.store.writeSummary(summary);
  await deps.store.writeReport(report);
  return report;
}
```

```ts
import { existsSync, readFileSync } from 'node:fs';
import { dirname, resolve } from 'node:path';
import { fileURLToPath } from 'node:url';
import { parseArgs } from 'node:util';
import { fetchEodhd } from './eodhd.js';
import { fetchKobo } from './kobo.js';
import { runDaily } from './run.js';
import { DataStore } from './store.js';

const repoRoot = resolve(dirname(fileURLToPath(import.meta.url)), '..', '..');

/** Minimal .env reader (KEY=value lines). Real environment variables win. */
function readDotEnv(path: string): Record<string, string> {
  if (!existsSync(path)) return {};
  const out: Record<string, string> = {};
  for (const line of readFileSync(path, 'utf8').replace(/^﻿/, '').split(/\r?\n/)) {
    if (line.trimStart().startsWith('#')) continue;
    const m = /^\s*([A-Z0-9_]+)\s*=\s*(.*?)\s*$/.exec(line);
    if (m) out[m[1]] = m[2].replace(/^["']|["']$/g, '');
  }
  return out;
}

async function main() {
  const { values } = parseArgs({ options: { 'data-dir': { type: 'string' }, backfill: { type: 'string' } } });
  const env: Record<string, string | undefined> = { ...readDotEnv(resolve(repoRoot, '.env')), ...process.env };
  const koboKey = env.KOBO_API_KEY;
  const eodKey = env.EODHD_API_KEY;
  if (!koboKey || !eodKey) {
    throw new Error('KOBO_API_KEY and EODHD_API_KEY must be set (in .env locally, or as GitHub secrets)');
  }
  const dataDir = values['data-dir'] ? resolve(process.cwd(), values['data-dir']) : resolve(repoRoot, 'data');
  const backfillPerRun = values.backfill !== undefined ? Number(values.backfill) : undefined;

  const report = await runDaily({
    fetchKobo: () => fetchKobo(koboKey),
    fetchEodhd: (symbol, from, to) => fetchEodhd(symbol, from, to, eodKey),
    store: new DataStore(dataDir),
    now: () => new Date(),
    backfillPerRun,
  });

  console.log(`Outcome: ${report.outcome} (trade date ${report.tradeDate})`);
  const bf = report.backfill;
  console.log(`Backfill: ${bf.ok.length} ok, ${bf.failed.length} failed${bf.stoppedEarly ? `; stopped early: ${bf.stoppedEarly}` : ''}`);
  for (const w of report.warnings) console.log(`Warning: ${w}`);
  console.log(`Data directory: ${dataDir}`);
}

main().catch((err) => {
  console.error(`Daily run failed: ${err instanceof Error ? err.message : String(err)}`);
  process.exit(1);
});
```

```ts
import type { History, Summary } from '../../pipeline/src/types';

const SYMBOL_RE = /^[A-Z0-9][A-Z0-9.]*$/;
const isJson = (r: Response) => (r.headers.get('content-type') ?? '').includes('json');

export async function loadSummary(fetchImpl: typeof fetch = fetch): Promise<Summary> {
  const r = await fetchImpl('data/summary.json', { cache: 'no-cache' });
  if (!r.ok || !isJson(r)) throw new Error('Price summary is not available yet');
  return (await r.json()) as Summary;
}

/** null = not tracked (unknown symbol, 404, or the host's HTML fallback page). */
export async function loadHistory(symbol: string, fetchImpl: typeof fetch = fetch): Promise<History | null> {
  if (!SYMBOL_RE.test(symbol)) return null;
  const r = await fetchImpl(`data/history/${symbol}.json`, { cache: 'no-cache' });
  if (r.status === 404 || (r.ok && !isJson(r))) return null;
  if (!r.ok) throw new Error(`Couldn't load price history (HTTP ${r.status})`);
  return (await r.json()) as History;
}
```

```ts
export type Route = { page: 'home' } | { page: 'stock'; symbol: string };

export function parseRoute(hash: string): Route {
  const m = /^#\/stock\/([^/?#]+)/.exec(hash);
  return m ? { page: 'stock', symbol: decodeURIComponent(m[1]).toUpperCase() } : { page: 'home' };
}

export const stockHref = (symbol: string) => `#/stock/${encodeURIComponent(symbol)}`;

export function useRoute(): Route {
  const [route, setRoute] = useState(() => parseRoute(window.location.hash));
  useEffect(() => {
    const onChange = () => {
      setRoute(parseRoute(window.location.hash));
      window.scrollTo(0, 0);
    };
    window.addEventListener('hashchange', onChange);
    return () => window.removeEventListener('hashchange', onChange);
  }, []);
  return route;
}
```

```ts
import type { SummaryRow } from '../../pipeline/src/types';

export type SortKey = 'symbol' | 'name' | 'sector' | 'close' | 'day' | 'week' | 'month' | 'volume';
export const TEXT_KEYS: SortKey[] = ['symbol', 'name', 'sector'];

export interface TableQuery {
  search: string;
  /** '' = all sectors */
  sector: string;
  sortKey: SortKey;
  sortDir: 'asc' | 'desc';
  showInactive: boolean;
}

function valueOf(r: SummaryRow, k: SortKey): string | number | null {
  switch (k) {
    case 'day':
    case 'week':
    case 'month':
      return r.changes[k];
    case 'close':
      return r.close;
    case 'volume':
      return r.volume;
    case 'symbol':
      return r.symbol;
    case 'name':
      return r.name;
    case 'sector':
      return r.sector;
  }
}

export function filterSort(rows: SummaryRow[], q: TableQuery): SummaryRow[] {
  const needle = q.search.trim().toLowerCase();
  const dir = q.sortDir === 'asc' ? 1 : -1;
  return rows
    .filter(
      (r) =>
        (q.showInactive || r.status === 'active') &&
        (!q.sector || r.sector === q.sector) &&
        (!needle || r.symbol.toLowerCase().includes(needle) || r.name.toLowerCase().includes(needle)),
    )
    .sort((a, b) => {
      const va = valueOf(a, q.sortKey);
      const vb = valueOf(b, q.sortKey);
      if (va === null || vb === null) {
        if (va === vb) return a.symbol.localeCompare(b.symbol);
        return va === null ? 1 : -1; // missing values last in both directions
      }
      const c = typeof va === 'number' && typeof vb === 'number' ? va - vb : String(va).localeCompare(String(vb));
      return c !== 0 ? c * dir : a.symbol.localeCompare(b.symbol);
    });
}

export function sectorsOf(rows: SummaryRow[]): string[] {
  return [...new Set(rows.map((r) => r.sector))].sort();
}
```

```ts
import { minusMonths } from '../../pipeline/src/dates';
import type { Bar } from '../../pipeline/src/types';

export interface StockStats {
  high: number;
  low: number;
  avgVolume: number;
  from: string;
  to: string;
  /** history reaches back a full 12 months */
  fullYear: boolean;
}

export function stockStats(bars: Bar[], asOf: string): StockStats | null {
  const start = minusMonths(asOf, 12);
  const window = bars.filter((b) => b.date > start && b.date <= asOf);
  if (window.length === 0) return null;
  const closes = window.map((b) => b.close);
  return {
    high: Math.max(...closes),
    low: Math.min(...closes),
    avgVolume: Math.round(window.reduce((s, b) => s + b.volume, 0) / window.length),
    from: window[0].date,
    to: window[window.length - 1].date,
    fullYear: bars[0].date <= start,
  };
}

export type Range = '1M' | '3M' | '6M' | '1Y' | 'All';
export const RANGES: Range[] = ['1M', '3M', '6M', '1Y', 'All'];
const MONTHS: Record<Exclude<Range, 'All'>, number> = { '1M': 1, '3M': 3, '6M': 6, '1Y': 12 };

export function barsInRange(bars: Bar[], range: Range, asOf: string): Bar[] {
  if (range === 'All') return bars;
  const start = minusMonths(asOf, MONTHS[range]);
  return bars.filter((b) => b.date >= start);
}
```

```tsx
    const dark = window.matchMedia('(prefers-color-scheme: dark)').matches;
    const chart = createChart(el, {
      autoSize: true,
      layout: { background: { color: 'transparent' }, textColor: dark ? '#e3e7ee' : '#1c2430' },
      grid: { vertLines: { visible: false }, horzLines: { color: dark ? '#2c3440' : '#eef0f3' } },
      rightPriceScale: { borderVisible: false },
      timeScale: { borderVisible: false },
    });
    const series = chart.addSeries(LineSeries, { color: dark ? '#5b9bff' : '#1668e6', lineWidth: 2 });
    series.setData(bars.map((b) => ({ time: b.date, value: b.close })));
    chart.timeScale().fitContent();
    return () => chart.remove();
  }, [bars]);

  return <div ref={ref} className="chart" role="img" aria-label="Closing price chart" />;
```

```tsx
export function StockPage({ summary, symbol }: { summary: Summary; symbol: string }) {
  const row = summary.stocks.find((s) => s.symbol === symbol);
  const [history, setHistory] = useState<History | null | undefined>(undefined);

  const [range, setRange] = useState<Range>('1Y');

    setError(null);

      (e: Error) => live && setError(e.message),
    );
    return () => {
      live = false;
    };
  }, [symbol, row]);

  const shownBars = useMemo(() => (history ? barsInRange(history.bars, range, summary.asOf) : []), [history, range, summary.asOf]);

  if (!row || history === null) return <NotFound symbol={symbol} />;
  const stats = history ? stockStats(history.bars, summary.asOf) : null;

        <p className="muted"><a href="#/">← All stocks</a></p>
        <h2>{row.name}</h2>

        </div>
        {row.largeMove && <p className="banner" title={LARGE_MOVE_TITLE}>⚠ Moved more than ±10% on the day: possibly a bonus issue or split, since prices are not adjusted.</p>}
        <p className="muted">History starts {formatDate(row.historyStart)}.</p>
      </section>

      <section className="card">
        <div className="range" role="group" aria-label="Chart range">
          {RANGES.map((r) => (
            <button key={r} aria-pressed={range === r} onClick={() => setRange(r)}>{r}</button>
          ))}
        </div>
        {error && <p role="alert">{error}</p>}
        {history === undefined && !error && <p className="muted">Loading history…</p>}
```
